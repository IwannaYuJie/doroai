# Doro AI

`doroai.net` 的静态主页项目。

## 部署方式

- 源码仓库：`IwannaYuJie/doroai`
- 生产分支：`main`
- 托管平台：Cloudflare Pages
- Pages 地址：`https://doroai.pages.dev`
- 自定义域名：`https://doroai.net`、`https://www.doroai.net`
- 自动发布：推送到 `main` 后由 Cloudflare 自动构建并上线
- DNS：Cloudflare 托管，DNSSEC 已配置

## 本地预览

这是一个不需要构建步骤的纯静态网站，直接打开 `index.html` 即可预览。
